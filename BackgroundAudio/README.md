# Example: Background Audio Player

A background audio player example running with UWP technology on the Xbox One, demonstrating SystemMediaTransportControls (SMTC) integration and background audio playback.

## Getting Started

Please follow our [tutorial](https://xboxdev.com/tutorials/background-audio-player) to create your own background audio player application for the Xbox One.

## Built with

* [Visual Studio](https://visualstudio.microsoft.com/) - C# Editor from Microsoft
* [Xbox One](https://afflnk.microsoft.com/c/1256010/476314/7806/) - Testing the application
* [Microsoft.NETCore.UniversalWindowsPlatform](https://www.nuget.org/packages/Microsoft.NETCore.UniversalWindowsPlatform/) - UWP Platform Support

## Features

* Background audio playback using MediaPlayer
* SystemMediaTransportControls (SMTC) integration — control playback via the Xbox Guide button
* Playlist management with next/previous navigation
* Shuffle support using Fisher-Yates algorithm
* Gamepad-friendly UI with XYFocus navigation
